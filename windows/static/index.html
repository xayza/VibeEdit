        Agent dock (Phase 5)

        Point an AI agent at this project's MCP server (from the agent's own terminal — there is no terminal emulator here):

        python windows\vibeedit.py mcp <project-folder>

        Protocol: newline-delimited JSON-RPC 2.0 on stdin/stdout (initialize, ping, tools/list, tools/call). Example agent commands:

        • tools/call vibeedit_project_get — read the whole open project.
        • tools/call vibeedit_timeline_apply {"ops": [{"op": "add_text", "track": "t1", "text": "Hello", "at": 0, "dur": 90}]} — add a caption.
        • tools/call vibeedit_project_validate — check the project for overlaps and dangling references.
