    Voiceover

    Voice generation works here when a backend is installed (Edge TTS via pip install edge-tts, or the Piper binary plus a .onnx model). Voice cloning is still not available — no cloning provider model exists in this build. Importing audio and placing it on the Voiceover track also works. Recording with your microphone works too (the browser asks for microphone permission; if you deny it, recording stops with a clear error and nothing is faked).

    Knowledge & Skills

    Agent knowledge lives in this project's data (lessons, facts, prefs, claims, proposals); skills live in windows/skills/. Nothing here invents content — every lesson, fact and skill body is text you type or text already stored.

      Vision

      OCR uses Tesseract, faces use OpenCV Haar cascades, cutout uses OpenCV grabCut, and learned cutout uses a user-supplied ONNX model. When a backend is missing the app says so plainly and returns nothing fake.

        Install plugin

        Installs a folder or .zip bundle into windows/plugins/ after manifest validation (unsafe ids, path traversal, symlinks, oversized or multi-folder bundles are refused). A newly installed plugin starts disabled — enable it in the Plugins panel. Nothing is executed during install.

          What this timeline can do — and what it cannot yet

          Works here (real): cut, trim, move, copy/paste, split at playhead, speed, keyframes (position, scale, opacity, volume, tilt), transitions, beat grid + snap to beat, Captions track with word-level karaoke chips, text presets with Vietnamese support, colour presets + LUT + adjustment layers, volume, fades, music ducking under voice, loudness normalisation, voiceover takes on the Voiceover track, H.264 export with burned-in subtitles, OTIO export/import, project saved as JSON next to footage, undo/redo, and an external AI agent via MCP (live tool count shown in the Agent dock) whose edits appear on the timeline and are undoable.

          Not yet in this Windows port (honestly labelled, never faked): in-app LLM chat generation, a real terminal for Claude Code / Codex inside the app (use your own terminal with python windows\vibeedit.py mcp <project-folder>), voice cloning, VieNeu TTS, and silence cutting. Audio tracks show waveform strips decoded from the real file (FFmpeg RMS peaks); if a file cannot be decoded, no strip is drawn rather than a fake shape.
